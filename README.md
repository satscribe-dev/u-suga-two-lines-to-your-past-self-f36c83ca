A program that writes one two-line warning to its past self to
`/output/entry.txt` — line one warns about one specific moment, line two
says why that moment mattered and what changed because of it.

Run it with Node 22:

```sh
node main.ts
```

The output is deterministic: every run writes the same 213-character,
two-line entry.
